Admin — Manage entries

This admin UI helps edit entries and (optionally) upload audio files directly into the GitHub repo. Requires a GitHub personal access token (repo scope).

Repository / Authentication

Notes: if you provide a token, the admin UI will attempt to upload audio files to audio/ and update data/entries.json in the repo using GitHub Contents API. No token is stored — it's used only for the current browser session.

Batch actions

When you're ready, you can commit your local changes to GitHub. If you have local audio files selected, they will be uploaded into audio/ and `data/entries.json` will be updated.
